# 📖 ハナの100日 / マロの180日 — 英語多読ドラマ × TOEIC 400→800

中学英語をマスターした学習者（≒TOEIC 400）が、**26週（6ヶ月）でTOEIC 800レベル**に到達することを目標にした英語多読アプリ。
「理解できる英語に大量に触れる（曝露量を増やす）ほど、英語は自然に出るようになる」という仮説にもとづいて設計しています。

`index.html` を開くだけ。ビルド不要・通信不要・完全オフライン動作。

## ふたつの物語

ホーム／ライブラリ上部のカードでいつでも切りかえられます。**進捗（読了・WPM・クイズ成績）は別々に記録**され、総語数・XP・連続日数・📒暗記ノートは両編で共有されます。

### 🐦 ハナの100日（日常会話 · 全100話 · 87,097語）

松山出身の**ハナ（24）**が、アメリカ・ポートランドで過ごす9ヶ月。カフェで注文する、道を尋ねる、症状を伝える——毎話ひとつの**日常会話の場面**がテーマ。Level 1〜4（約600語→約1,200語）。

### 🔬 マロの180日（日常＋専門 · 全180話 · 184,577語）

ポスドク研究者の**マロ（31）**が、ドイツ・ハイデルベルクの研究所で過ごす1年余り。真面目だが注意散漫でミスばかり、人と話すのが苦手で一人が好き、特技は水泳、趣味はキャンプ——という人物が、文化の違いとラボの失敗をくぐり抜けて一人前の研究者になるまで。

日常会話に加えて**専門的な会話**（プロトコル、実験の議論、統計、学会発表、論文執筆、査読対応）を織り込み、フレーズは毎話「日常3つ＋🔬専門2つ」。Level 1〜5（約700語→約1,350語）。舞台がドイツなので、役所手続き・日曜閉店・ゴミ分別・静粛時間・直言文化といった**文化差**のエピソードも豊富です。

> 主人公マロは性別を特定せず、英語では they/them で描いています。

## TOEIC 400→800・26週プラン

ホームの「📋 26週プランの詳細を見る」からいつでも確認できます。週ごとの目標はアプリが学習データから自動チェックします。

| 週 | フェーズ | 内容 | 目安スコア |
|----|---------|------|-----------|
| W1–4 | 基礎回復 | 第1–25話（L1）· 🎧0.8x · WPM80 | 400→450 |
| W5–9 | 語彙増強 | 第26–50話（L2）· 単語パック基礎 · 🎧0.9x · WPM100 | 450→550 |
| W10–14 | 実戦の入口 | 第51–75話（L3）· シャドーイング毎日 · 🎧1.0x · WPM120 · W14に公式問題集① | 550→650 |
| W15–18 | 物語完走 | 第76–100話（L4）· パック実戦 · WPM135 | 650→700 |
| W19–22 | 2周目・速読 | 全話を🚀速読＆🎧1.1x多聴 · W21に公式問題集② | 700→750 |
| W23–26 | 仕上げ | 復習待ちゼロ維持 · 苦手回再読 · 本番ペース | 750→800 |

毎日のメニュー（40〜60分）: ①新しい1話15分 → ②📒ノート復習5〜15分 → ③きのうの話をシャドーイング10分 → ④単語パック10語。忙しい日は②だけでもストリークは続きます。

> 📌 正直な注意書き: 400→800は一般に600〜800時間相当。このアプリが作るのは語彙・速読・多聴・会話の型という「基礎体力」（26週で約150〜250時間）。W14とW21ごろに市販の公式問題集を時間を計って通しで解き、本番形式に慣れてください。

## 📒 暗記ノート（SRS搭載）

覚えたいものをワンタップでノートに保存 → **忘却曲線に沿って自動で再出題**（翌日→2日→4日→7日→14日→30日→60日→90日）。

- 保存元: 物語の下線単語（辞書シート）／今日のフレーズ／TOEIC知識カード／単語パック／自分で自由に追加
- フラッシュカード復習: タップでめくって「○おぼえた／△まだ」。△は同じ日にもう一度出ます。英→日/日→英の切替可
- **TOEIC単語パック500語** 内蔵（基礎250＝400–600帯／実戦250＝600–800帯、例文付き）。ホームの「今日のTOEIC単語10」から毎日10語ずつ
- **TOEIC知識カード54枚**（Part1〜7の解法・頻出知識・学習戦略）を日替わりで1枚ずつ
- CSV書き出し対応（Ankiなど外部ツールに取込可能）

## 使い方

ダブルクリックで `index.html` を開くだけです。ローカルサーバーで見る場合:

```bash
python3 -m http.server 8901
```

iPad で読む場合は、`index.html` をファイルアプリに入れて開くか、Safari で開いて「ホーム画面に追加」してください（オフラインで動きます）。
学習データは端末の localStorage に保存されます。機種変更のときは ⚙️設定 →「バックアップ 書き出し／読み込み」を使ってください。

## コンテンツ設計

バラバラな100題ではなく、**1本の連続ドラマ**にしました。続きが気になることが毎日の習慣化に直結し、同じ登場人物・同じ世界観の反復が初学者の読解負荷を下げるからです。

> 松山出身のハナ（24）が、アメリカ・ポートランドで過ごす9ヶ月間の物語。
> ホストファミリーのミラー家、勤め先の「ブルーバード・カフェ」、親友エマ、隣人チェンさん——
> 4月の到着から12月の帰国まで、全100話。

各話に **日常会話の場面テーマ** をひとつ割り当てています（カフェで注文／病院で症状を伝える／道を尋ねる／苦情に対応する／意見を述べる…）。読んだその日に使える形で身につくよう、場面と表現をセットで学びます。

### レベル設計（ハナの英語上達と連動）

| 話数 | レベル | 語数 | 文法の上限 |
|------|--------|------|-----------|
| 1–25 | Level 1 はじめの一歩 | 約600語 | 現在形・過去形・can/want |
| 26–50 | Level 2 なれてきた毎日 | 約800語 | + will/going to・because/if |
| 51–75 | Level 3 ひろがる世界 | 約1,000語 | + 現在完了・比較級・句動詞 |
| 76–100 | Level 4 じゆうな会話 | 約1,200語 | 自然な会話英語 |

**総語数 87,097語**。会話行の比率は全レベル平均 64〜70% と高く、「読む」がそのまま会話の型のインプットになります。復習フェーズの多聴を含めると、6ヶ月の総曝露量は10万語を超えます。

## 続けるための仕組み

- **毎日1話の日次フロー** — 読む → りかいチェック（3問） → 使えるフレーズ5つを音読
- **次回予告** — 読み終わると必ず翌日のあらすじが出る。「続きが気になる」で終わらせる
- **🔥 連続日数・XP・レベル**（たまご→ひよこ→…→あおい鳥）と **バッジ19種**
- **📖 語数マイルストーン** — 1,000語から10万語まで、達成時に紙吹雪
- **🗓 学習ヒートマップ**と **📈 WPMグラフ** — 読む速度の成長が目に見える
- **🎧 リスニング** — 文ごとのハイライト再生、速度0.6〜1.1倍、🗣シャドーイングモード（各文のあとに真似る間が入る）
- **単語ヒント** — 難語に下線、タップで意味。辞書は引かず読み飛ばす前提の補助

## 6ヶ月ロードマップ

- **Day 1〜100**: 毎日1話ずつ、新しい物語を読む
- **Day 101〜180**: 同じ100話を「🎧聞く／🚀速読／📖再読」の日替わりメニューで復習し、会話の型を定着させる

2周目のハナの物語が驚くほどラクに読めること自体が、成長の証拠になります。
